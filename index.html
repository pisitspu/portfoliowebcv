About Me

ผมเป็นนักศึกษาสาขาวิทยาการคอมพิวเตอร์และนวัตกรรมการพัฒนาซอฟต์แวร์ คณะเทคโนโลยีสารสนเทศ มหาวิทยาลัยศรีปทุม มีความหลงใหลในการแก้ปัญหาด้วยซอฟต์แวร์และการสร้าง Web Application แบบ End-to-End

ผมมีทักษะในการพัฒนาทั้งฝั่ง Frontend ด้วย React, JavaScript, Tailwind CSS และฝั่ง Backend โดยเน้นการออกแบบ RESTful API Architecture, JWT Authentication รวมทั้งจัดการฐานข้อมูลทั้ง PostgreSQL และ MySQL

นอกจากนี้ยังสนใจในการประยุกต์ใช้เทคโนโลยี AI สมัยใหม่ เช่น การทำระบบ Retrieval-Augmented Generation (RAG) และมีความเข้าใจในวงจร CI/CD, Containerization ด้วย Docker เพื่อส่งมอบระบบที่เสถียรและพร้อมใช้งานจริง

Featured Project

Eduguide — RAG Education Guidance Chatbot

แชทบอทอัจฉริยะช่วยค้นหาตัวเองและการศึกษาที่เหมาะสมที่สุด

Problem

ผู้เรียนและนักเรียนจำนวนมากสับสนเรื่องแนวทางการเรียนต่อ ข้อมูลหลักสูตรกระจัดกระจาย และการแชทกับ AI ทั่วไปมักมีอาการประสาทหลอน (Hallucination) หรือตอบข้อมูลไม่ตรงกับบริบทจริง

Solution

พัฒนาระบบ AI Chatbot สถาปัตยกรรม Retrieval-Augmented Generation (RAG) ดึงฐานข้อมูลหลักสูตรและสายอาชีพมาอ้างอิง ทำให้คำตอบแม่นยำและช่วยวิเคราะห์ความชอบของผู้เรียนได้อย่างตรงจุด

บทบาทและความรับผิดชอบ: ออกแบบ Data Pipeline, จัดทำระบบ RAG เชื่อมต่อ LLM API และพัฒนาหน้าจอแชทสำหรับผู้ใช้งาน
