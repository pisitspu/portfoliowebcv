## 🚀 Featured & Key Projects

### 🌟 1. Eduguide — RAG Education Guidance Chatbot *(Featured Project)*
> แชทบอทอัจฉริยะช่วยแนะแนวทางการเรียนต่อและค้นหาตัวตนที่เหมาะสมที่สุดผ่านคลังข้อมูลหลักสูตร

* **Problem:** ข้อมูลหลักสูตรและการศึกษาต่อกระจัดกระจาย อีกทั้งการใช้งาน AI โมเดลทั่วไปมักตอบข้อมูลที่กว้างเกินไปหรือไม่สอดคล้องกับหลักสูตรจริง (Hallucination)
* **Solution:** ออกแบบระบบ Retrieval-Augmented Generation (RAG) เชื่อมต่อคลังข้อมูลหลักสูตร เพื่อดึงบริบทที่ถูกต้องก่อนสร้างคำตอบ ช่วยให้ผู้เรียนประเมินความถนัดได้อย่างแม่นยำ
* **Role:** ออกแบบ Data Pipeline, จัดทำระบบ RAG เชื่อมต่อ LLM API และพัฒนา Interface สำหรับผู้ใช้งาน
* **Tech Stack:** Python, RAG Architecture, Vector DB, RESTful API

## 🤖 Vibe Coding Process & Reflection

โปรเจกต์นี้สร้างขึ้นภายใต้กระบวนการ **Vibe Coding** ซึ่งเน้นให้ผู้พัฒนาเป็น **Software Architect & Prompt Engineer**:

1. **Context-Driven Prompting:** กำหนด Context ชัดเจนทั้งบทบาท (Full-Stack Developer), ผู้ชมเป้าหมาย (Tech Recruiter), และข้อกำหนดทางเทคนิค (Responsive 100%, Dark Minimalist)
2. **Iterative Problem Solving:** ใช้ AI ในการช่วย Scaffold โครงสร้าง UI และ Style ด้วย Tailwind CSS พร้อมตรวจสอบ Logic และ Layout ด้วยตนเอง (Human-in-the-loop)
3. **Security First:** ตรวจสอบและควบคุมไม่ให้มีการฝัง API Keys หรือรหัสผ่านลงในโค้ดบน Git Repository
